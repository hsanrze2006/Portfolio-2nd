# Dev Nux — Personal Portfolio

A personal developer portfolio created to introduce myself, present my skills and projects, and provide ways to get in touch.

## ✨ Sections

- **Home:** Introduction and links to portfolio content
- **About:** Background and development journey
- **Skills:** Technologies and tools
- **Projects:** Project cards and links
- **Contact:** Contact information and social profiles
- **CV:** Downloadable PDF resume

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Font Awesome

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/hsanrze2006/portfolio-2nd.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
